About Me

Python developer with a Master’s degree in Data Science (highest honours) and a Bachelor’s degree in Software Engineering from ISTIC, University of Carthage. I like building prototypes and improving them step by step. In my Master’s thesis I built a complete data pipeline: I collected prompts from public datasets, used LLM APIs to generate 11,995 programs, classified them automatically with LLM judges, cross-checked the labels, cleaned and deduplicated the data, then compared several approaches (static analyzers, transformer, graph model) to build a scoring model reaching 0.936 ROC-AUC. During my internship at ST2i I wrote a Python module that extracts and structures candidate data from CVs, and as a freelancer I built an ERP with a Python OCR module that extracts, normalizes and validates ID numbers from scanned documents. I have also built a multi-step LLM agent with LangGraph that collects data from external APIs and produces a structured analysis. I enjoy AI, data and automation problems, and I like to start simple, test quickly and propose ideas.
