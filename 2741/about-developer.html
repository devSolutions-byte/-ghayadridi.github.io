About Me

Research Master’s graduate in Data Science and Smart Services (highest honours) from ISTIC, University of Carthage, with a Bachelor’s degree in Software Engineering. In my thesis I used generative AI to build a security dataset: 401 prompts sent to two LLMs produced 11,995 programs, which I labeled with LLM judges, cross-checked with static analyzers and manual review, deduplicated and split without leakage. I then trained HAGM-DFA, a graph neural network that detects vulnerabilities (0.936 ROC-AUC), and compared it with existing detection tools. This work led to two articles, currently under review. I also studied data poisoning attacks on a semi-supervised model. I am looking for a PhD on generative AI, cybersecurity datasets and robust attack detection.

Research Interests

Generative AI · Cybersecurity Datasets · Robust Detection

  • Using generative AI to build labeled datasets for evaluating security tools, as I did for code in my thesis.
  • Dataset quality: label reliability, duplicates, data leakage and the metrics that measure them.
  • Attack detection that stays robust to AI-generated and adversarial attacks (data poisoning project).
  • Experimental research: comparing detection tools on the same data with rigorous, reproducible evaluation.
