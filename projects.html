Vulnerability Detection through Semantic Analysis of Prompts and Generated Code

A hybrid NLP and Graph Neural Network approach

Code assistants such as Copilot, ChatGPT or Claude are transforming software development, but the code they produce can hide security flaws (SQL injection, command injection…), and the same prompt may yield safe or vulnerable code. Existing detectors look only at the code and ignore the developer’s intent. My thesis introduces a new idea: analysing the prompt and the generated code jointly. Vulnerability detection in generated code

1–4 A reliable prompt–code benchmark

401 prompts (SecurityEval, CodeLMSec), 2 generators (Codestral, Qwen-Coder-Plus), 11,995 generated programs. Cross LLM-judge labeling checked with CodeQL / flawfinder and manual review, then deduplication and prompt-level split to prevent leakage → 6,291 pairs, 72 CWE, Python & C.

5–6 HAGM-DFA detector

Heterogeneous Attention Graph Model for Data-Flow-Aware vulnerability detection. Code becomes a graph (AST, token order, control flow, data flow) linked to the prompt by cross-attention edges, encoded with UniXcoder and HeteroConv layers.
